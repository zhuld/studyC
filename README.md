# 《C程序设计语言》交互读本

《The C Programming Language》第 2 版（中文简体译本）的交互式阅读实现：**前言与序 + 8 章 + 3 个附录，共 188 个小节**。

逐节阅读教材原文，看到可运行的程序即可一键送进代码工作台，在线编译运行。纯静态页面，无构建步骤、无第三方运行时依赖。

---

## 本地运行

任意静态服务器即可（**不要**用 `file://` 直接打开，课程数据靠 `fetch` 加载，需经 HTTP）：

```powershell
npx serve .
# 或
python -m http.server 8080
```

然后打开 `http://localhost:8080/`。

## 部署

推送到 GitHub 仓库后在 Settings → Pages 选择 `main` 分支根目录即可。部署需要根目录下的 `index.html`、`style.css`、`*.js`、`course-content.json` 与 `images/`。

## 怎么用

访问 https://zhuld.github.io/studyC/

**读**：正文占满窗口宽度（无最大宽度限制）。左侧三级目录（章 → 小节 → 三级小节）点击即跳转正文，滚动时目录自动高亮当前小节；目录可收缩，窄屏下变成抽屉。顶部工具条显示当前章节的阅读进度，可调正文大小、切换明暗主题与全屏阅读。

**跑**：正文里「带 `main` 的完整程序」（共 38 处）下方有「载入编辑器 / ▶ 运行」按钮。每个代码块右上角都能一键复制。

**工作台**：可拖动、缩放的代码编辑器，支持行号、C 语法高亮、Tab 缩进（4 空格，Shift+Tab 反缩进）与 `Ctrl+Enter` 运行。需要标准输入的程序在 stdin 栏填写。页面加载后默认隐藏，点击顶部工具条的「打开代码工作台」按钮即可打开；关闭后可从顶部重新打开，拖动与缩放都能用方向键操作。

**在线编译**：默认以 **C89**（教材描述的 ANSI C）提交到 [Wandbox](https://wandbox.org)，可切换编译器与 C 标准；服务不可用时页面仍可打开（退化为内置占位编译器）。

当前章节、字号、主题与目录状态记在浏览器 localStorage 里，刷新后会恢复这些偏好；主题首次访问时跟随系统，阅读进度条按当前章节的滚动位置实时计算。清除浏览器数据即恢复默认。

## 课程内容

| 部分 | 小节数 | 说明 |
| --- | --- | --- |
| 前言与序 | 6 | 出版者的话、中文版序、译者序、序、第一版序、引言 |
