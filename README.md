# C 语言 · 交互课程

围绕 C 语言核心知识组织的 8 章交互式课程：课程阅读区与可独立移动、缩放的代码工作台分离，
代码可在线编译运行，练习自动判题。纯静态页面，可直接部署到 GitHub Pages。

## 教程依据

- 《C程序设计语言（第2版·新版）》，机械工业出版社 2004-1，ISBN 9787111128069，徐宝文 等译
- 原书 *The C Programming Language*, 2nd ed., Prentice Hall 1988, ISBN 0-13-110362-7
  ——迄今最新的正式版本
- 课程按 PDF 目录逐节组织；课程数据不转录原书正文，也不提供原书练习集。
- 课程中的辅助讲解、示例与练习采用原创表述。

## 功能

- **8 章课程、91 个 PDF 小节教程**：按教材目录顺序逐节讲解；另保留 64 个交互专题的示例与练习
- **课程与代码分离**：章节切换不会覆盖工作台代码；从示例或练习载入代码时工作台自动显示
- **逐项对照教材目录**：PDF 目录中的 91 个章节/小节各自独立呈现并可从目录跳转；目录外的交互专题归入补充内容
- **瀑布式左栏目录**：章节条目下就地下拉该章小节，逐条下落呈现；当前章默认展开，再点一次即收起（窄屏目录为浮层抽屉，选中小节后自动收起）
- 在线编译：调用 [Wandbox](https://wandbox.org) API（CORS 开放，浏览器直连，无需后端）
  - 14 个纯 C 编译器可选（gcc-13.2.0-c、clang-17.0.1-c 等），支持 c89/c99/c11 标准切换，
    默认采用 C89（教材描述的是 ANSI C，即 C89）
  - 支持 stdin 标准输入；服务器不可用时自动退化为内置的占位编译器配置，页面仍可打开
- **结构与内容分离**：页面逻辑与教程内容分属 `app.js` / `course-content.json`，增改教程无需改动页面代码
- 教材正文直接可编译：正文中含 `main` 的完整程序（31 处，如 1.6、5.10、7.1）在代码块下方提供
  「载入编辑器 / ▶ 运行」入口，可即时在线编译；判定规则由 `code-blocks.js` 与 `tools/test_code_blocks.js` 共同保证
  （原书「代码＋中文旁注」排版块、跨块片段与省略写法不计入）
- 代码编辑器：行号、C 语法高亮、Tab 缩进、`Ctrl+Enter` 运行（零依赖，无 CDN）
- 独立代码工作台：可拖动、调整大小或关闭；关闭后可从页面右下角重新打开
- 明暗主题：可在页面右上角切换，主题选择会保存在浏览器本地
- 自动判题：程序输出与标准答案逐字比对（忽略行尾空白），通过即盖章

## AI 辅助设计说明

本项目在界面构思、视觉设计和部分课程内容整理及代码实现过程中使用了 AI 工具辅助。AI 生成的建议和内容均由项目维护者审阅、修改，并通过课程数据检查、语法检查及练习回归测试验证。AI 工具仅作为辅助，不替代教材、C 语言标准或人工核对；课程讲解和示例以原创表述为主。

任意静态服务器即可，例如：

npx serve .

## 部署到 GitHub Pages

1. 推送本目录到 GitHub 仓库；
2. 仓库 Settings → Pages → Source 选择 `main` 分支根目录；
3. 访问 `https://<用户名>.github.io/<仓库名>/`。

无构建步骤。请通过静态 HTTP 服务器打开页面，以便加载独立的课程 JSON 文件。

## 文件结构

| 文件 / 目录 | 说明 |
| --- | --- |
| `index.html` | 页面骨架：左栏瀑布式目录、右栏教程、浮动代码工作台；内容容器由脚本填充 |
| `style.css` | 「活页讲义 × 深色终端」样式；明暗主题只覆盖 CSS 变量 |
| `lessons.js` | 加载 `course-content.json`，校验后交给 `app.js` 并广播就绪事件 |
| `app.js` | 渲染教程、编辑器（行号 + 语法高亮）、Wandbox 调用、自动判题与进度存档 |
| `code-blocks.js` | 判定教材正文里哪些代码块是「带 `main` 的完整程序」（页面与测试共用） |
| `course-content.json` | 课程数据：8 章、91 个 PDF 小节教程，以及 64 个交互专题的讲解/示例/练习 |
| `images/` | 教程插图，供页面直接引用 |
| `tools/` | 开发辅助脚本（数据管线与回归测试），不参与页面部署 |
| `md/` | 教材正文 Markdown 书稿（插图在 `md/images/`），课程数据的唯一来源；经人工整理并纳入版本控制 |
| `c-programming-language-2nd-edition-simple-chinese.pdf` | 教材 PDF，作为数据管线的输入与人工核对依据 |

`tools/` 内：

| 文件 | 说明 |
| --- | --- |
| `pdf_to_md.py` | 数据管线第 1 步：按 PDF 书签切分单元并转换为 Markdown |
| `md_to_course.py` | 数据管线第 2 步：把 Markdown 书稿写回 `course-content.json` 并自校验 |
| `test_course_data.js` | 回归测试：课程数据的结构与完整性（不联网） |
| `test_code_blocks.js` | 回归测试：正文代码块的在线编译判定（不联网） |
| `test_judge.js` | 回归测试：用参考答案跑通全部题目（需联网） |

页面部署只需要仓库根目录下的 `index.html`、`style.css`、`*.js`、`course-content.json` 与 `images/`。

## 数据管线

课程数据由教材 PDF 生成，但**书稿 `md/` 经人工整理，是课程数据的唯一来源**（已纳入版本控制）：

```powershell
python tools/pdf_to_md.py            # 第 1 步：PDF → md/*.md（仅当 md/ 尚无书稿时执行）
python tools/pdf_to_md.py --force    # 第 1 步的强制重跑：会整体覆盖 md/（含旧图片清理）
python tools/md_to_course.py         # 第 2 步：md/*.md → course-content.json（并复制插图到 images/）
```

日常修改教程只跑第 2 步即可。第 1 步默认**拒绝覆盖**已有 `md/`：脚本输出与人工整理后的书稿并不同
（例如三级小节标题、图题注、图片命名），重跑会丢失这些整理结果，必须显式加 `--force`。

脚本按自身位置（`tools/`）回退一级定位输入输出，因此可在任意目录调用（通常在仓库根目录执行）。
输出是确定的：同一 PDF 每次运行得到逐字节相同的结果。

- `tools/md_to_course.py --verify` 只做一致性校验（不改写 JSON、不复制图片），适合提交前检查；
  校验失败会以退出码 1 结束。
- 生成结果固定为 8 章、91 个 PDF 小节教程与 64 个交互专题，`tools/test_course_data.js` 会核对这一总量。
- 页面不转录原书正文：教程正文、辅助讲解与练习均为原创表述，数据中只保留小节编号与页码。

## 本地存储

页面用 `localStorage` 记住以下偏好（清除浏览器数据即恢复默认）：

| 键 | 用途 |
| --- | --- |
| `krc-ch1-theme-v1` | 明暗主题；在首屏绘制前恢复，避免闪烁 |
| `krc-course-toc-collapsed-v1` | 目录是否收缩（窄屏默认收缩） |
| `krc-course-chapter-v1` | 上次阅读的章节 |
| `krc-ch1-progress-v1` | 已通过的练习与专题 |

## 开发与测试

- 无构建步骤、无第三方运行时依赖，改完直接刷新页面即可。
- 提交前运行回归测试（脚本都在 `tools/`，前两个不联网）：

```powershell
node tools/test_course_data.js
node tools/test_code_blocks.js
node tools/test_judge.js   # 需联网，会调用 Wandbox
```

- 代码注释统一使用简体中文；`app.js` 中大量 `data-*` 属性是渲染、滚动高亮与进度标记之间的约定，
  新增元素时请保持命名一致。


## 课程范围

教程按所列第二版教材的章节与小节顺序组织；课程数据保留每节对应的原书页码，但页面不转录、也不提供原书正文与练习集的阅读入口，辅助讲解为原创表述。示例与练习保留为可交互专题；目录外的扩展专题会单独标注。课程数据不复录原书正文：

| 章节 | 覆盖重点 |
| --- | --- |
| 1 | 入门、变量、循环、字符流、数组、函数与作用域 |
| 2 | 类型、常量、声明、运算符、条件表达式与求值规则 |
| 3 | 分支、循环、结构化退出、标号与跳转 |
| 4 | 函数、递归、作用域、存储期、初始化与预处理 |
| 5 | 指针、数组、字符串、命令行参数、函数指针与复杂声明 |
| 6 | 结构体、结构指针、自引用结构、查找、联合与函数接口 |
| 7 | 格式化 I/O、流、文件、错误处理、变长参数与标准库工具 |
| 8 | 文件描述符、低级 I/O、缓冲字符读取、分配器、目录接口与随机访问 |
